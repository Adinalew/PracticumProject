📚 Study Hub
Study Hub is a Django web application that helps students stay organized and prepare for exams by allowing them to upload notes, extract text, and generate study materials — all in one place.

🔧 Features
✅ User Registration & Login

📤 Upload Files (PDF, TXT, Images)

🔎 Automatic Text Extraction

📓 View Notes per File

📄 Generate AI Study Reviews

🧠 Create Flashcards

🧪 Generate Practice Quizzes

🔊 Convert Notes to Audio

💾 Persistent Sessions (saved in DB)
